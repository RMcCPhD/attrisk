Trial design model

Summary

We will construct a design stage model using aggregate-level data to predict attrition rates based on trial design features while accounting for differences in trial duration. The model will be similar to that described in NICE Technical Support Document 3 (3.2. Rate data: Binomial likelihood and cloglog link) for modelling rates where event times are not available.

Model description

Likelihood

For each trial \(i\), we will specify the model likelihood using the binomial distribution:

\[\begin{aligned} r_i \sim \text{Binomial}(N_i, \theta_i) \\ \end{aligned}\]

Where \(i\) indicates a trial, \(r\) represents the observed number of attrition events, \(N\) represents the number of participants and \(\theta\) represents the probability of attrition at time \(t\).

Informed by findings from our previous IPD analysis of attrition rates, we will use the Gompertz cumulative distribution function as a link function for \(\theta_i\):

\[\begin{aligned} F(t_i) &= 1 - \exp \left(-\frac{b_i}{a_i} \exp(a_i t_i) \right), \end{aligned}\]

where \(a \geq 0\) is the shape parameter and \(b \geq 0\) is the rate parameter for trial \(i\) at time \(t\).

We will specify a fixed intercept for \(a\) across all trials and place covariates on \(a\) for each trial:

\[\begin{aligned} \log(a_i) = \alpha_i + \beta_{1i}X_{1i} + \dots + \beta_{ki}X_{ki}, \end{aligned}\]

where \(\alpha_i\) is the fixed intercept, \(\beta_{1i} \dots \beta_{ki}\) are coefficients estimated for covariates and \(X_{1i} \dots X_{ki}\) are the covariates.

We will specify random rate intercepts (i.e. across trials) for \(b\):

\[\begin{aligned} b_i = \exp(\beta_{0i} + u_i), \end{aligned}\]

where \(\beta_{0i}\) is the log-baseline hazard rate for trial \(i\) and \(u_i\) is the rate intercept.

Priors

We will specify weakly informative priors for \(\alpha_i\) and \(\beta_{ki}\). We will not specify a prior for \(b\), but will place a weakly informative prior on rate intercept \(\beta_{0i}\) and random effect \(u_i\) to enable random variability between trials.

\[\begin{aligned} \alpha_i, \beta_{ki}, \beta_{0i}, u_i &\sim \text{Normal}(0, 1). \end{aligned}\]

Model code (without coefficient shrinkage)

data {
  int<lower=1> I; // Number of trials
  int<lower=0> r[I]; // Observed attrition events per trial
  int<lower=0> N[I]; // Number of participants per trial
  vector[I] dt; // Time in weeks per trial
  vector[I] var1; // Covariate
}

parameters {
  real b_mu; // Log-baseline hazard rate
  vector[I] u; // Random intercept for rate
  real a_raw; // Baseline shape parameter
  real beta; // Covariate coefficient
}

transformed parameters {
  vector[I] b; // Rate
  vector[I] a; // Shape
  vector[I] p; // Probability of attrition
  
  for (i in 1:I) {
    a[i] = a_raw + beta * var1[i];
    b[i] = exp(b_mu + u[i]);
    p[i] = 1 - exp(-b[i]/a[i] * (exp(a[i] * dt[i]) - 1));
    
    // Check values
    // if (i <= 5) {
    //   print("a_raw = ", a_raw, ", var1[i] = ", var1[i], "beta = ", beta);
    //   print("a = ", a[i], ", b[i] = ", b[i]);
    //   print("p[i] = ", p[i]);
    // }
  }
}

model {
  b_mu ~ normal(0, 0.5);
  a_raw ~ normal(0, 1);
  beta ~ normal(0, 0.5);
  u ~ normal(0, 1);
  
  // Likelihood
  for (i in 1:I) {
    r[i] ~ binomial(N[i], p[i]);
  }
}

generated quantities {
  vector[I] r_new; // Predicted count
  vector[I] p_new; // Predicted probability of attrition
  vector[I] rate; // Baseline hazard rate
  
  for (i in 1:I) {
    p_new[i] = 1 - exp(-b[i]/a[i] * (exp(a[i] * dt[i]) - 1));
    r_new[i] = binomial_rng(N[i], p_new[i]);
    rate[i] = exp(b_mu);
  }
}

Model code (with coefficient shrinkage)

A double-exponential (Laplace) prior will be specified to introduce shrinkage to covariate coefficients.

\[\begin{aligned} \end{aligned}\] 
data {
  int<lower=1> I; // Number of trials
  int<lower=0> r[I]; // Observed attrition events per trial
  int<lower=0> N[I]; // Number of participants per trial
  vector[I] dt; // Time in weeks per trial
  vector[I] var1; // Covariate
}

parameters {
  real b_mu; // Log-baseline hazard rate
  vector[I] u; // Random intercept for rate
  real a_raw; // Baseline shape parameter
  real beta; // Covariate coefficient
}

transformed parameters {
  vector[I] b; // Rate
  vector[I] a; // Shape
  vector[I] p; // Probability of attrition
  
  for (i in 1:I) {
    a[i] = a_raw + beta * var1[i];
    b[i] = exp(b_mu + u[i]);
    p[i] = 1 - exp(-b[i]/a[i] * (exp(a[i] * dt[i]) - 1));
    
    // Check values
    // if (i <= 5) {
    //   print("a_raw = ", a_raw, ", var1[i] = ", var1[i], "beta = ", beta);
    //   print("a = ", a[i], ", b[i] = ", b[i]);

  }

model {
  b_mu ~ normal(0, 0.5);
  a_raw ~ normal(0, 1);
  beta ~ double_exponential(0, 1); // Shrinkage factor of 1
  u ~ normal(0, 1);
  
  // Likelihood
  for (i in 1:I) {
    r[i] ~ binomial(N[i], p[i]);
  }
}

generated quantities {
  vector[I] r_new; // Predicted count
  vector[I] p_new; // Predicted probability of attrition
  vector[I] rate; // Baseline hazard rate
  
  for (i in 1:I) {
    p_new[i] = 1 - exp(-b[i]/a[i] * (exp(a[i] * dt[i]) - 1));
    r_new[i] = binomial_rng(N[i], p_new[i]);
    rate[i] = exp(b_mu);
  }
}

Prediction

After evaluating model fit (i.e. convergence, posterior predictive checks), we will extract posterior point estimates (i.e. mean and 95% confidence intervals) from the fitted model. In this approach (withou gauging uncertainty), we can use the estimates to make predictions about attrition rates based on trial design features.
